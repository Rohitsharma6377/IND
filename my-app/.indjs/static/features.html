INDJS comes packed with features that make building modern web applications fast, fun, and incredibly productive.

Performance

Lightning Fast Builds

Powered by esbuild and Vite for instant hot module replacement and sub-second builds

Optimized Production

Automatic code splitting, tree shaking, and minification for optimal bundle sizes

Smart Caching

Intelligent caching strategies to speed up subsequent builds and deployments

Developer Experience

File-Based Routing

Intuitive routing based on your file structure. Create a file, get a route automatically

Hot Module Replacement

See your changes instantly without losing application state

TypeScript Support

First-class TypeScript support with automatic type checking and IntelliSense

Zero Config

Sensible defaults that work out of the box. Configure only when you need to

Full-Stack Features

API Routes

Build serverless API endpoints right alongside your pages

Built-in Authentication

JWT-based auth with bcrypt hashing, sessions, and middleware support

Database Adapters

Connect to PostgreSQL, MongoDB, SQLite, or use Prisma ORM

Server-Side Rendering

Render pages on the server for better SEO and initial load performance

Styling & UI

Tailwind CSS

Pre-configured Tailwind CSS for rapid UI development

CSS Modules

Scoped CSS with CSS Modules support built-in

Responsive Design

Mobile-first utilities and responsive design patterns

Deployment

Deploy Anywhere

Deploy to Vercel, Cloudflare Workers, AWS, or any Node.js hosting
