## 📦 **Components Created**

### **1. TodoCard.jsx**
- Displays a single todo item
- Checkbox with animation
- Delete button (appears on hover)
- Props: `todo`, `onToggle`, `onDelete`

### **2. ExpenseCard.jsx**
- Displays a single expense
- Category icon with color
- Amount and date
- Delete button
- Props: `expense`, `onDelete`

### **3. StatCard.jsx**
- Displays statistics
- Colored numbers
- Label
- Props: `value`, `label`, `color`

### **4. TabButton.jsx**
- Tab navigation button
- Active state with gradient
- Icon and label
- Props: `active`, `onClick`, `icon`, `label`

### **5. CategoryCard.jsx**
- Expense category summary
- Icon with colored background
- Category name and amount
- Props: `category`, `amount`

### **6. EmptyState.jsx**
- Empty list placeholder
- Icon, title, message
- Props: `icon`, `title`, `message`
