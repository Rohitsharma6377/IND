## 🚀 CLI Commands Summary

### Project Management
```bash
indjs create my-app              # Create new project
indjs dev                        # Start development
indjs build                      # Build for production
indjs start                      # Start production server
```

### Code Generation
```bash
indjs generate page about        # Generate page
indjs g component Button         # Generate component
indjs g api users                # Generate API route
indjs g layout dashboard         # Generate layout
indjs g hook useAuth             # Generate custom hook
indjs g util formatDate          # Generate utility
indjs g test Button              # Generate test
```

### AI-Powered
```bash
indjs ai scaffold component Form # AI scaffolding
indjs ai docs                    # Generate docs
indjs ai refactor                # Refactoring suggestions
```

### Testing
```bash
indjs test                       # Run unit tests
indjs test --watch              # Watch mode
npm run e2e                     # E2E tests
```

### Deployment
```bash
indjs deploy vercel             # Deploy to Vercel
indjs deploy netlify            # Deploy to Netlify
indjs deploy docker             # Generate Docker config
indjs deploy aws                # Deploy to AWS
indjs deploy static             # Static export
```

### Mobile & Desktop
```bash
indjs desktop dev               # Run as Electron app
indjs mobile build              # Build for mobile
indjs mobile android            # Open Android Studio
indjs mobile ios                # Open Xcode
```
