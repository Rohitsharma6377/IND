# Changelog

All notable changes to INDJS will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.14] - 2025-12-08

### Added
- 🚀 Comprehensive framework documentation
- 📦 TypeScript configuration with strict type checking
- 🎨 ESLint and Prettier for code quality
- 📝 Contributing guidelines
- 🧪 Enhanced testing setup with Vitest and Playwright
- 🔧 Advanced configuration system
- 🌐 Multiple deployment platform support
- 🤖 AI-powered CLI with Ollama integration
- 🗄️ Database integration (MongoDB, PostgreSQL, SQLite, Prisma)
- 🔒 Built-in authentication system (JWT, OAuth, Sessions)
- 📱 Mobile and desktop support (Capacitor, Electron)
- ⚡ Vite integration for faster development
- 🎯 Advanced routing with middleware support
- 💾 Caching system (LRU, Redis)
- 📊 Observability and metrics dashboard

### Changed
- 📖 Improved README with comprehensive examples
- 🏗️ Better project structure
- ⚡ Enhanced build performance
- 🎨 Updated styling system

### Fixed
- 🐛 Removed placeholder logo from README
- 🧹 Cleaned up test artifacts
- 📦 Optimized npm package size
- 🔧 Fixed .gitignore and .npmignore configurations

### Removed
- ❌ Empty test directories
- ❌ Old build artifacts
- ❌ Unnecessary development files from npm package
